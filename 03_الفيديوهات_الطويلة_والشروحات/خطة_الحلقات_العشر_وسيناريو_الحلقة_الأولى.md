#### المشهد 04: الكود السري للأتمتة (Frappe Custom Script) | [08:30 - 11:00]
* **السرد الصوتي (Voiceover):**
  > "للمطورين ومدراء التقنية، هذا هو الكود الذي ينقذ الملايين. لا نعدل في الكود المصدري للنظام لكي لا نخسر التحديثات، بل نستخدم Server Script بسيطاً يضمن إحكام الرقابة التلقائية."
* **العرض المرئي:**
  * استعراض بيئة الكود بإضاءة داكنة (Dark Mode IDE) مع تسليط الضوء على الدالة البرمجية وسلاسة تنفيذها.

```python
# frappe-framework: Server Script to enforce BOQ Budget Validation
def validate_subcontractor_claim(doc, method):
    for item in doc.items:
        # جلب الكمية المعتمدة في جدول الكميات للمشروع
        boq_limit = frappe.db.get_value(
            "Project BOQ Item",
            {"parent": doc.project, "item_code": item.item_code},
            "allocated_qty"
        )
        
        # حساب إجمالي المنفذ سابقاً + الحالي
        total_executed = frappe.db.sql("""
            SELECT SUM(qty) FROM `tabPurchase Invoice Item`
            WHERE project = %s AND item_code = %s AND docstatus = 1
        """, (doc.project, item.item_code))[0][0] or 0.0

        if (total_executed + item.qty) > boq_limit:
            frappe.throw(
                f"خطأ رقابي فادح: تجاوزت كمية البند ({item.item_code}) الحد المعتمد في الـ BOQ بمقدار {(total_executed + item.qty) - boq_limit}! يرجى إصدار أمر تغيير (Change Order) معتمد أولاً."
            )
```
