# 🎙️ ميثاق الهندسة الصوتية وقواعد النطق المعتمدة
## قناة «إتقان — الذكاء المؤسسي» | ITQAN — Institutional Intelligence

---

### 1. الصوت الرسمي المعتمد للقناة:
* **المحرك:** Google Cloud / Gemini Generative Audio (Chirp 3 HD Architecture).
* **معرف الصوت (Voice Identifier):** **`ar-XA-Chirp3-HD-Charon`**
* **المواصفات:** لغة عربية فصحى معاصرة (`ar-XA`)، نبرة وقورة، رصينة، وإخبارية فخمة تناسب صناع القرار والقيادات المؤسسية.
* **الجودة:** معدل عينات 48,000 Hz Stereo / 192 kbps.

---

### 2. القاموس الصوتي الإلزامي للمصطلحات التقنية (Phonetic Rules):

| المصطلح الأصلي | الكتابة الإلزامية في سكريبت الإلقاء | النطق الصوتي الفعلي للمحرك |
| :--- | :--- | :--- |
| **ERPNext** | `ERP نكست` | ينطق حروف **(E - R - P)** إنجليزية واضحة تليها كلمة **نكست** العربية |
| **ERP** | `ERP` | ينطق الحروف الإنجليزية الثلاثة **(E - R - P)** منفصلة |
| **Frappe** | `فرابي` | ينطق **فرابي** بنطق عربي سليم وواضح دون ابتلاع الحروف |
| **Frappe Flow** | `فرابي قوقل فلوا` | ينطق **فرابي قوقل فلوا** بوضوح تام |
| **Frappe Studio** | `فرابي استديوا` | ينطق **فرابي استديوا** بنبرة عربية صريحة |
| **Insights** | `إنسايتس` | ينطق **إنسايتس** |
| **Module** | `موديول` | ينطق **موديول** |
| **PDF** | `بي دي إف` | ينطق **بي دي إف** |
| **OCR** | `أو سي آر` أو القراءة الآلية | حروف إنجليزية أو المصطلح المباشر |

---

### 3. بروتوكول الإنتاج والحوكمة الصوتي (Voice Gate Protocol):
1. **التحليل الصوتي المسبق:** فحص السكريبت وتحويل أي مصطلحات أجنبية طبقاً للقاموس الصوتي أعلاه.
2. **التوليد عبر محرك Chirp 3 HD:** استدعاء خوادم Google وتقسيم النصوص الطويلة إلى شرائح (< 500 حرف) لضمان الاستقرار.
3. **بوابة الاعتماد الإلزامية (Human Voice Gate):** 
   * **ممنوع منعاً باتاً دمج الفيديو أو تغيير الماستر المرئي قبل تقديم الملف الصوتي للمالك واستلام موافقته الصريحة.**
4. **الدمج والتزامن:** بعد الاعتماد، يتم ضبط الترجمة ثنائية اللغة (ASS) المتزامنة بدقة، ودمج شريط الصوت مع المؤثرات البصرية.
